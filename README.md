# 暗記カード

問題と答えを登録し、ランダム出題、カテゴリー分類、苦手カードの復習ができる静的Webアプリです。

## 主な機能
- カードの追加・編集・削除
- カテゴリー分類
- ランダム出題
- すべて・苦手・未回答の出題モード
- 覚えた・苦手の学習結果保存
- 検索とカテゴリー絞り込み
- JSONバックアップ
- PC、タブレット、スマートフォン対応

## 公開方法
1. GitHubで `flashcard-app` というPublicリポジトリを作成します。
2. 4ファイルをアップロードします。
3. Settings → Pagesでmainブランチのrootを公開します。
